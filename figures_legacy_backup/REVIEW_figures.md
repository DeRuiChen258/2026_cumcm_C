## 6. 电池退化模型（经授权新增，替换吞吐代理）

> 授权变更范围：新增 `code/optimize/degradation.py`；`solve_stage_lp` / `solve_two_stage_lp` / `solve_q2` 各增加一个**默认 0** 的 `throughput_penalty` 参数。既有模型路径逐位不变（见 §6.3 回归验证）。

### 6.1 模型与参数

| 环节   | 方法                                                    | 参数（LFP 典型值，均为显式入参）             |
| ---- | ----------------------------------------------------- | ------------------------------ |
| 循环分解 | ASTM E1049 四点雨流计数（先取极值点，含 0.5% 容量最小摆幅滤波）              | `min_swing_frac = 0.005`       |
| 寿命曲线 | Wöhler / Coffin-Manson：$N(DoD)=N_{100}\cdot DoD^{-k}$ | $N_{100}=6000$ 次、$k=1.1$       |
| 损伤累积 | Miner 线性累积 $D=\sum_i c_i/N(DoD_i)$（半循环计 0.5）          | —                              |
| 健康状态 | $SOH=1-D_{年}$（按 365/334 天年化）                          | —                              |
| 经济折算 | $C_{deg}=D_{年}\cdot(\text{capex})$                    | 800 元/kWh × 12000 kWh = 960 万元 |

DoD 以**额定容量**（12000 kWh）为基准，因此 1200–10800 kWh 可用窗口的最大摆幅对应 DoD = 0.8（`selftest` 中已用解析值校验）。

### 6.2 模型自检（`python3 -m code.optimize.degradation`，8/8 通过）

单次完整循环（6000→10800→6000，DoD=0.4）、等幅双摆配对、单调斜坡=半循环、平直轨迹零损伤、深度加权单调性、可用窗口摆幅 = DoD 0.8（损伤 = $1/N(0.8)$ 精确到 1e-12）、DoD=1 摆幅 = $1/N_{100}$、亚阈值纹波被滤除。

### 6.3 结果与回归验证

| 内容              | 结果                                                                                                                                                 |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 纯经济最优策略（β=0）    | 年衰减 **8.59%**（SOH 91.4%），退化成本 82.5 万元/年                                                                                                            |
| CVaR 风险层（β=0.9） | 年衰减 8.90%，退化成本 85.4 万元/年（风险下降 15.8%、退化仅 +0.3pp）                                                                                                    |
| 退化定价前沿          | ρ=0 → 总成本 448.1 万元、衰减 8.59%；**ρ=0.20 元/kWh → 总成本最低 424.9 万元、衰减 5.03%**；ρ=0.40 → 总成本回升至 429.5 万元、衰减 1.88%                                           |
| 参数敏感性           | $N_{100}\in[4000,8000]$、$k\in[0.9,1.3]$ 时年衰减区间 **5.24%–13.98%**（退化成本 50.3–134.2 万元）                                                                |
| 消融 SOH 列（Fig.9） | M0 7.25% → M1 8.38% → M2 8.43% → M3 7.52%；风险分支 M4 8.68%                                                                                            |
| **回归验证**        | 重跑全流程后，**五份 `result*.xlsx` 与 29/31 个非计时类产物逐位一致**；仅 `results/paper_numbers.json`（含清洗耗时字段）与 `results/verification_report.json`（含图件计数检查）因计时/图集数量变化而更新 |

结论（写入论文的表述）：**忽略电池退化并非经济最优**——把退化按 0.20 元/kWh 定价，可使年衰减从 8.6% 降到 5.0%，同时把“电费 + 退化”总成本降低约 5.2%。
